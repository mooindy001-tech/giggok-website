
# GIGGok Website

เว็บไซต์ตัวอย่างสำหรับงานระบบไฟฟ้า / รีโนเวท / BOQ

## วิธีรันบน Windows

1. ติดตั้ง Python 3
2. เปิด Command Prompt ในโฟลเดอร์โปรเจกต์
3. ติดตั้ง Flask

    pip install flask

4. รันเว็บ

    python app.py

5. เปิดเบราว์เซอร์ไปที่

    http://127.0.0.1:5000

## Admin

- URL: http://127.0.0.1:5000/admin
- Username: admin
- Password: 1234

ควรเปลี่ยนรหัสผ่านก่อนนำขึ้นออนไลน์จริง

## สิ่งที่มีในเวอร์ชันนี้

- หน้าแรก
- รายการบริการ
- ผลงาน
- ติดต่อ
- Admin Login
- เพิ่มผลงาน
- ลบผลงาน
- เก็บข้อมูลใน data.json
